## Key Decisions

1. **Supabase over raw PostgreSQL** — Simplifies deployment, adds auth and realtime
2. **pgvector over dedicated vector DB** — Reduces complexity, leverages existing PostgreSQL
3. **Redis for caching** — Industry standard, supports multiple use cases
4. **Incremental migration** — Avoids big bang, reduces risk
5. **Ports & Adapters pattern** — Enables provider swapping without core changes
